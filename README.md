# Mounvix — NAS в телефоне

Собственный (не клон) продукт: Android-приложение для работы с файлами и медиа на своих серверах + легкий серверный агент (Go) с Web-UI. Спецификация: [docs/specs/2026-11-17-mounvix-design.md](docs/specs/2026-11-17-mounvix-design.md).

## Структура
- `server/` — Go-сервер (health, Web-UI, WebDAV, API, бэкап, плагины) — этапы M1+
- `server/internal/app/assets/` — статика Web-UI, встраивается в серверный бинарник.
- `android/` — Android-приложение (Kotlin/Compose, база FileBox, M2+)
- `packaging/` — init.d/systemd и сборка opkg/deb/tar.gz
- `plugins/` — манифест и примеры плагинов (M7)
- `scripts/` — локальные сборки/QA
- `docs/` — спецификация и планы

## Быстрый старт (WSL/Ubuntu)
```bash
export PATH="$HOME/tools/go/bin:$PATH"   # Go установлен локально в ~/tools/go
cd server && go test ./...               # тесты
VERSION=0.2.0 ./scripts/build-server.sh  # кросс-сборка 6 архитектур -> dist/server/
```
Проверка сервера:
```bash
./dist/server/linux_amd64/mounvix-server -addr 127.0.0.1:48100 &
curl -s http://127.0.0.1:48100/health
```

## Начальный доступ администратора
На чистой установке сервер создаёт `admin` с криптографически случайным 256-битным временным паролем и сохраняет его в `<data_dir>/admin-bootstrap-password` с правами `0600`. Пароль в журнал не выводится — журнал содержит только путь к файлу. Прочитайте файл локально или по SSH под системной учётной записью сервера, войдите в панель и смените пароль `admin` в разделе «Пользователи»: после успешного сброса bootstrap-файл удаляется. Для стандартных пакетов путь по умолчанию: Entware `/opt/var/mounvix/admin-bootstrap-password`, Debian `/var/lib/mounvix/admin-bootstrap-password`; фактический путь задаётся `data_dir` в `config.json` (в быстром старте по умолчанию `./data`).

При обновлении автоматически меняется только известный встроенный пароль старой установки; остальные учётные записи, права доступа и пользовательские пароли сохраняются. Каталог `data_dir` — служебное хранилище: он не выдаётся через WebDAV, файловый API, медиа/AI или публичные ссылки, даже если попал внутрь настроенного корня. Bootstrap-пароль не попадает в новые резервные копии и не восстанавливается из старых.

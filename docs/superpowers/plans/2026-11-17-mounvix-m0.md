# Mounvix M0 — скелет репозитория и сборки (реализация)

> **For agentic workers:** REQUIRED SUB-SKILL: superpower-executing-plans (native execution, выбрано владельцем: «GO», экономия токенов). Steps use checkbox syntax.

**Goal:** Создать рабочий скелет репозитория Mounvix: Go-сервер с health-эндпоинтом, кросс-сборка на 6 арок, каркасы упаковки (opkg/deb/tar.gz), README/NOTICE/лицензия — база для этапов M1–M8.

**Architecture:** Один Go-модуль `server/` (cmd + internal), статический бинарник без CGO; bash-скрипты `scripts/` (WSL) собирают матрицу; `packaging/` — init.d/systemd и сборка пакетов; `android/` и `web/` — заготовки (реальный Android — с M2, Web-UI — с M1). Все секреты — только в Basic Memory.

**Tech Stack:** Go 1.22+ (stdlib), bash, git; позже: htmx (embed), modernc sqlite, Android/Kotlin-Compose (FileBox-база).

**Spec:** `docs/specs/2026-11-17-mounvix-design.md` (v0.2)

## Global Constraints
- Порт по умолчанию 48100; конфиг `/opt/etc/mounvix/config.json` (Entware), `/etc/mounvix/config.json` (deb).
- `CGO_ENABLED=0`, `GOOS=linux`, `GOARCH` ∈ {arm64, arm, mipsle, mips, amd64, 386}; бинарник `mounvix-server`.
- Лицензия GPL-3.0 + NOTICE; токены/пароли в репозиторий не попадают.
- Нет внешних зависимостей в M0 (кроме stdlib).
- Сборки — скриптами (`scripts/*.sh`) в WSL; Android-сборка — локальным тулчейном `C:\android-dev`.
- Экономия токенов: скрипты вместо ручных команд; вывод проверок — короткий.

## Review Focus
- Health/версия должны переживать кросс-компиляцию и запуск на mips без cgo и без /proc.
- Скрипты должны работать при отсутствии `go` в PATH (использовать явный путь/`$GO`).
- `.ipk` — legacy gzip-tar (не Debian `ar`); проверять распаковкой.
- Чистый клон → сборка без локальных артефактов.
- Никаких секретов в скриптах/логах/конфигах в репо.
